# ADR 0012 — 本地使用观测与上下文估算

状态：Accepted  
日期：2026-10-26  
范围：P23-01；本地可选search/read记录、只读聚合与静态估算。

## 决定

- 新增独立于生命周期history的usage事件。只有进程显式设置`SKILL_HUB_USAGE_LOG`绝对JSONL路径才记录；默认读取行为不写盘。不自动修改任何宿主配置，不上传记录。
- 事件仅含时间、来源界面（cli/mcp/web/library）、工具阶段、Skill名称、成功/错误码、正文/附件首段或续读、返回文本的字符/字节数及启发式估算。不保存query、描述、正文、附件路径、错误详情、凭据。仅说明Hub服务层成功返回文本，不证明宿主接收、实际采用、执行或任务完成。
- 不重复统计fetch内部调用read。分页续读与首段分列，重复首段请求仍是独立调用，不能称为唯一会话/任务数。Web人工浏览单列；无法识别实际MCP客户端或原生磁盘读取，保留这个覆盖限制。
- 单独JSONL只追加；日志写失败发出不含私有数据的stderr告警，保留原读取/搜索结果。聚合遇坏行保留健康记录并标记不完整；未开启/文件缺失不解释为历史从未使用。首版不自动删除/轮转用户日志，报告大小上限并要求维护者归档。
- 静态估算拆分name/description元数据、SKILL.md全文、可配置首段。默认不读取附件，不加总为必然注入，不加载付费模型或tokenizer依赖。显式上下文窗口仅用于估算比例，不预设宿主窗口或剩余预算。
- 初版使用版本化`utf8-heuristic-v1`：ASCII字符每4个计1，其余Unicode码点计1.5，向上取整；这是透明的粗略比较指标，不是tokenizer结果或保证误差界。同时报告UTF-16长度、Unicode码点数与UTF-8字节。JSON封装、工具定义、对话历史、重复注入、缓存与模型计费不在估算内；真实模型token与费用保持null。
- 只读静态扫描在独立观测禁用作用域运行，绝不能把盘点动作记录为Skill使用。新增usage/context-cost仅提供CLI/library，首版不新增runtime工具、不改Web UI。

## 验收

P23-02扩展：用户要求Web展示，并明确“使用lv”为使用率而非等级。新增只读使用/预算视图与固定参数HTTP接口；使用率按所选时间/来源内当前catalog所有Skill成功正文首段请求数计算，分类/文本/状态过滤不改分母。过滤排序先于分页，未知末尾；Web默认MCP，人工浏览可显式选择。此扩展不改变记录默认关闭、隐私字段或估算非账单的边界，也不新增runtime工具。

合成沙箱验证默认无写入、显式记录、来源分离、分页与fetch不重复、隐私字段、坏日志/写失败、日期过滤、计数与估算口径、静态盘点不污染日志、完整性错误、编译CLI及MCP/Web入口。保留现有只读和精简runtime契约。
