# Community code of conduct

Treat contributors and users with respect. Constructive disagreement about implementation is welcome; harassment, threats, discriminatory language, doxxing and publishing private information are not.

Keep issues and PRs focused on reproducible behavior and the proposed change. Respect other people's authorship and licenses. Do not submit secrets or personal Skill catalogs as examples.

Maintainers may edit or remove abusive material, close disruptive discussions and restrict repeated violations. Report misconduct through a private GitHub contact with the maintainer; do not publish private evidence in a public issue. There is no guaranteed response time for this volunteer project.
