# ADR 0007 — Hub 按需加载作为默认接入

- 状态：Accepted
- 日期：2026-09-05
- 背景：用户明确要求 Agent 不安装单个 Skill，由 Hub 统一安装与提供内容。原生目录 symlink 仍参与宿主发现，不能实现这一目标。

## 决策

Hub canonical 是安装和更新入口。Agent 只连接 MCP，精确名称直接 fetch，未指定时 search → fetch；目录浏览、附件和长文分页由同一读取服务提供。sync 保留为显式兼容能力，不再作为新增 Skill 的必经步骤。

CLI/MCP 共用列表和读取服务。读取只能访问已登记 Skill 根内的普通文本文件；支持 canonical 根 symlink，但拒绝内部越界、路径穿越、环路与特殊文件。结果返回实际内容 hash 和续读偏移，调用方按需加载而不是把全库正文注入。

OpenCode 首先采用独立启动配置：继承已有模型/provider 设置，禁用原生 Skill 工具和外部 Skill 发现，仅接入 Hub MCP。凭据仅在进程内传递，不落入仓库或运行报告。原有宿主配置和 Skill 文件保留，普通 OpenCode 启动方式不受此入口改变。

## 验收与限制

验收包括全库元数据/正文的真实 MCP 分页读取和 hash 对照、路径拒绝、实际 OpenCode 模型工具轨迹、精确加载、附件读取、检索和更新后新会话。全库读取验收不等于执行每个 Skill 的外部业务流程。

MCP 返回内容是任务上下文，不能覆盖宿主 system prompt 或代替执行授权。OpenCode 自带内部技能可能仍存在于程序里，但原生 skill 工具须被禁用，模型不可依赖其目录列表。其他宿主逐个接入验收，不能外推 OpenCode 结果。

内容风险扫描、token 估算审计、可选本地调用统计与语义检索是后续独立能力；本决策不把预留接口标记为已实现。
